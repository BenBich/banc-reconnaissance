Banc d'essai de reconnaissance des cartes

Le téléphone (ou la webcam) reconnaît-il vos cartes sleevées ? Ce test le mesure avec vos vraies cartes, sans rien acheter. Rien n'est envoyé : la caméra et les calculs restent dans votre navigateur.

1Les cartes à tester

On prend quelques cartes d'un deck (par défaut 20) : ce sont celles que vous allez présenter devant la caméra.
Des cartes joueur du Core Set tirées au hasard (pratique si vous n'avez pas de lien sous la main).

2Les images de référence

Ce que le programme connaît d'avance pour reconnaître une carte. On peut tester les deux façons et les comparer.
Des images de cartes au hasard ajoutées aux références, pour voir si le programme se trompe quand il y a beaucoup de cartes possibles (en images MarvelCDB uniquement).

3Le test avec la caméra

Posez le téléphone sur un support (ou tenez-le fixe) au-dessus d'un tapis uni, la carte à plat dans le cadre. On vous demande une carte à la fois : présentez-la, retirez-la, présentez la suivante.

4Les résultats

Le test est fait quand toutes les cartes ont été présentées. Copiez ou téléchargez les résultats pour me les envoyer : je m'en sers pour améliorer la méthode.
